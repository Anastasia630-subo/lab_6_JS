# Подготовка к защите лабораторной №6

**Тема:** Основы JavaScript. **Цель:** освоить JavaScript и взаимодействие JavaScript с HTML.

## Что сделано

Создана веб-страница с пятью функциями и отдельными формами ввода. После нажатия кнопки JavaScript считывает значения, проверяет их, вычисляет результат и показывает его на странице без перезагрузки.

## Основные функции (файл `index.html`)

1. `pow(x,n)` — `let result = 1n`, цикл `for` выполняет умножение `result *= x` ровно `n` раз. Операторы `**` / `Math.pow()` не используются.
2. `gcd(a,b)` — алгоритм Евклида: пока `b !== 0n`, вычисляется остаток `a % b`, далее `(a,b)` заменяется на `(b,остаток)`. Возвращается `a`.
3. `minDigit(x)` — число превращается в строку `toString()`, делится на символы `split('')`, цифры преобразуются `map(Number)`; цикл ищет минимальную.
4. `pluralizeRecords(n)` — используется остаток `n % 100n` для 11–14 и `n % 10n` для окончаний 1, 2–4 и остальных. Меняются и существительное, и сказуемое.
5. `fibb(n)` — две переменные хранят соседние числа; каждую итерацию сумма становится следующим числом. `BigInt` необходим для точного F(1000).

## Как устроен вывод

- `document.getElementById('pow-x')` — найти поле HTML по атрибуту `id`.
- `.value` — прочитать текст из поля.
- `addEventListener('submit', ...)` — назначить обработчик отправки формы.
- `event.preventDefault()` — отменить обычную отправку формы/перезагрузку.
- `output.textContent = calculate()` — вставить результат в текст HTML-элемента безопасно.
- `try/catch` — перехватить ошибку некорректного ввода и показать её вместо результата.
- `classList.add()`/`remove()` — поменять оформление результата/ошибки.

## Контрольные вопросы из методички

**1. Что такое JavaScript? Его особенности?**
JavaScript — язык программирования для добавления логики и интерактивности на веб-страницы. Обычно выполняется в браузере; умеет реагировать на события пользователя и изменять страницу через DOM без полной перезагрузки.

**2. Как подключить скрипт к странице?**
- Встроенный: `<script> ... </script>` внутри HTML — удобно для небольшой лабораторной, но увеличивает HTML-файл.
- Внешний: `<script src="script.js" defer></script>` — отдельный переиспользуемый файл, `defer` откладывает выполнение до завершения разбора HTML.
- В атрибуте события, например `onclick="..."`, — возможно, но смешивает разметку с логикой, поэтому обычно не рекомендуется.
В нашей лабораторной используется **встроенный `<script>` в конце `body`**, поскольку методичка просит JavaScript, встроенный в код веб-страницы.

**3. Что такое DOM?**
Document Object Model — объектная модель документа, древовидное представление HTML-страницы, с элементами которого JavaScript может работать.

**4. Какой объект является входной точкой для взаимодействия с веб-страницей?**
`document` — доступ к текущему HTML-документу и его элементам.

**5. Как получить доступ к элементам веб-страницы?**
`document.getElementById('id')`, `document.querySelector('.class')`, `document.querySelectorAll('selector')` и другие методы.

## Вероятные дополнительные вопросы

- **`let` / `const`?** `let` — переменная, которую можно переопределять; `const` — привязка, которую нельзя переназначить.
- **`function`?** Объявляет функцию с параметрами, `return` возвращает результат.
- **`for` и `while`?** Циклы; `for` удобен при известном числе повторений, `while` выполняется пока условие истинно.
- **`%`?** Остаток от деления. Используется в НОД и правилах склонения.
- **`===` и `!==`?** Строгое равенство и строгое неравенство (без преобразования типов).
- **`BigInt`?** Тип целых чисел произвольной точности; литерал `1n` — BigInt.
- **`value` и `textContent`?** `value` считывает значение поля ввода; `textContent` меняет текст элемента.
- **Почему нет PHP и MySQL?** По заданию лабораторной №6 требуется JavaScript и HTML, работающие в браузере; база данных не нужна.
