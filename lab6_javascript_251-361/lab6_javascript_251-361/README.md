## Работа с функциями

1. `pow(x, n)` — степень целого числа `x` при натуральном `n` (1–1000), без `**` и `Math.pow()`.
2. `gcd(a, b)` — НОД неотрицательных целых чисел; для пары `(0, 0)` принято значение `0`.
3. `minDigit(x)` — минимальная цифра неотрицательного целого числа.
4. `pluralizeRecords(n)` — грамотная фраза о количестве найденных записей.
5. `fibb(n)` — F(n) при n от 0 до 1000, где F(0)=0, F(1)=1. `BigInt` обеспечивает точные значения.

Поля форм принимают целые числа; некорректный ввод показывает сообщение об ошибке. При нажатии кнопки JavaScript перехватывает отправку и обновляет результат без перезагрузки страницы.

## Контрольные примеры

- pow(2, 5) = 32; pow(-2, 3) = -8.
- gcd(48, 18) = 6; gcd(0, 15) = 15.
- minDigit(58326) = 2; minDigit(0) = 0.
- pluralizeRecords(1): «...была найдена 1 запись»; (2): «...были найдены 2 записи»; (5): «...было найдено 5 записей»; (11): «...было найдено 11 записей»; (21): «...была найдена 21 запись».
- fibb(0) = 0; fibb(1) = 1; fibb(10) = 55; fibb(100) = 354224848179261915075.
